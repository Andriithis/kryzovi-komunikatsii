# Формула встановлення меж

*Визнати емоцію → поставити межу → запропонувати варіант дії.*

1. **Визнайте емоцію:** «Я бачу, що ви дуже злі».
2. **Встановіть межу:** «Я готовий (-а) вас вислухати, але не дозволю погрожувати іншим».
3. **Запропонуйте варіант дії:** «Давайте поговоримо тут».

Кожен крок має доказову основу (див. зв'язки).

**Коротка практика:** 60–90 секунд із розгніваною, але неозброєною людиною: слухайте → назвіть емоцію → межа → варіант дії.
