# Семиступенева модель кризової комунікації

*Алгоритм із попереднього курсу: ідентифікація → контакт → факти → підтримка → інформування → переконання → моніторинг.*

1. **Ідентифікація** — оцінка ситуації й ризиків, пріоритет фізичної безпеки.
2. **Контакт** — самопрезентація, спокійний тон, відкрита поза.
3. **Факти** — збір об'єктивної інформації, уточнення, перефразування.
4. **Підтримка** — визнання емоційного стану, емпатія без оцінок.
5. **Інформування** — правдива й зрозуміла інформація, варіанти, наступні кроки.
6. **Переконання** — аргументація через безпеку, спільний пошук рішень.
7. **Моніторинг** — фіксація домовленостей, залишкові ризики, координація з іншими службами.

Кроки 1–4 — стабілізація, 5–7 — вплив і завершення.
