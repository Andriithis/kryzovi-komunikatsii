# БЕЗПЕКА → ПОЧУЙ → ПІДТРИМАЙ → ДОПОМОЖИ

*Чотирикрокова модель, на якій побудована чинна одноденна програма тренінгу з кризових комунікацій.*

Кроки:
1. **Безпека** — оцінити загрози для себе, людини, оточення.
2. **Почуй** — встановити контакт, вислухати.
3. **Підтримай** — стабілізувати стан (дихання, заземлення).
4. **Допоможи** — перейти до конкретних дій і перенаправлення.

## Досвід застосування

Після першого проведення (група 15 осіб): перший модуль спрацював, модулі 2–4 і сама чотирикрокова схема на практиці виявились важкими для відпрацювання. Обговорюється перехід на структуру «одна навичка — один модуль».

## Зв'язки

- `напруга ↔` [[Одна навичка — один модуль]] — модель дає порядок дій, але погано ділиться на заняття для відпрацювання.
- `споріднене` [[Контакт — перша навичка]] — крок «Почуй» по суті і є встановленням контакту.
