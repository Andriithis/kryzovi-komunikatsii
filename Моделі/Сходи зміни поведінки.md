# Сходи зміни поведінки

*Модель ФБР для кризових переговорів: активне слухання → емпатія → довіра → вплив → зміна поведінки. Сходинки не можна перестрибнути.*

1. **Активне слухання** — знижує збудження: людина «витягує» емоцію в слова, і її стає менше.
2. **Емпатія** — людина відчуває, що її зрозуміли.
3. **Довіра (rapport)** — поліцейського сприймають як того, з ким можна домовитись.
4. **Вплив** — лише тепер людина чує прохання.
5. **Зміна поведінки.**

Типова помилка поліцейського — одразу п'ята сходинка: «Покладіть», «Відійдіть», «Заспокойтеся». Модель пояснює, *чому* це не працює.

Для тренінгу це сильніша рамка, ніж список технік: кожна техніка — інструмент, щоб піднятися на сходинку.

У попередньому курсі Андрія модель називається «Сходи поведінкових змін» (BCSM) з тим самим висновком: право на вплив треба заслужити послідовною побудовою довіри.
