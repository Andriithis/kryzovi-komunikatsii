# Медіа

Фото й зображення для презентацій і нот. Репозиторій публічний, тому сюди можна класти лише те, що можна показувати всім.

## Правила

1. **Тільки свої або дозволені зображення:** власні фото, зображення з відкритою ліцензією (вказати джерело), схеми, зроблені для бази.
2. **Без впізнаваних людей без їхньої згоди.** Обличчя, жетони, номери авто, адреси — закрити або не викладати. Кадри з нагрудних камер і службові матеріали сюди не кладемо.
3. **Назва файлу каже, що це:** `2026-11-10-trening-flipchart.jpg`, а не `IMG_1234.jpg`.
4. **Підпис і джерело** — рядком у таблиці нижче.

## Папки

- `Тренінги/` — фото з тренінгів (фліпчарти, зал без облич або зі згодою).
- `Схеми/` — схеми й діаграми.
- `Ілюстрації/` — зображення з відкритою ліцензією.
