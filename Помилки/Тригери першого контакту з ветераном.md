# Тригери першого контакту з ветераном

*Частина звичних поліцейських дій для людини з бойовим досвідом звучить як загроза або знецінення.*

**Уникати:**
- команд криком («Лягай!»);
- раптового наближення, дотику без попередження;
- тактичного ліхтаря в обличчя;
- «Ти просто перепив?»;
- «Ніяких обстрілів немає».

**Що допомагає:** представитися; один спокійний голос; на рівні очей, без різких рухів; зорієнтувати (місце, дата, «тут ви в безпеці»); повага до служби; варіант дії, що зберігає гідність.

**Контекст після повернення:** горе, виснаження, провина; безсоння, сімейний конфлікт; відчуття несправедливості й загнаності в кут. Якщо йдеться про мобілізацію, СЗЧ чи ТЦК, говорити про людину й наступний крок, а не про закон.
