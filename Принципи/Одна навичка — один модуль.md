# Одна навичка — один модуль

*Тренінг краще будувати так, щоб кожен модуль відпрацьовував одну конкретну навичку, а не крок абстрактної схеми.*

Крок схеми («підтримай», «допоможи») — це мета, а не дія. Учасник не знає, що саме робити руками й словами. Навичка («встановити контакт», «Я-повідомлення», «заземлення») — це дія, яку можна показати, повторити й отримати зворотний зв'язок.

Метод на кожен модуль: коротка лекція → демонстрація → практика учасників → зворотний зв'язок.

## Зв'язки

- `напруга ↔` [[БЕЗПЕКА → ПОЧУЙ → ПІДТРИМАЙ → ДОПОМОЖИ]] — схема дає порядок, навички дають уміння.
- `обґрунтовує →` [[Контакт — перша навичка]] — перший модуль спрацював саме тому, що був навичкою.
