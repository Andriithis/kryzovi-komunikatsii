# Спершу людина, потім її характеристика

*Коректна мова називає людину, а не її діагноз чи обмеження: «людина з інвалідністю», а не «інвалід».*

Ярлик зводить людину до однієї ознаки і запускає стереотип ще до розмови. Приклади:

| Не кажемо | Кажемо |
|---|---|
| інвалід | людина з інвалідністю |
| колясочник, прикутий до візка | людина, яка користується кріслом колісним |
| сліпий, глухий | людина з порушенням зору / слуху; незряча людина |
| сурдопереклад | переклад жестовою мовою |
| психічно хворий | людина з ментальним розладом |
| наркоман, бомж | людина з наркозалежністю, людина без житла |
| здорові / нормальні люди | люди без інвалідності |
