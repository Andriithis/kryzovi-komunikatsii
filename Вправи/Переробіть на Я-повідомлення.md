# Переробіть на Я-повідомлення

*Учасник переробляє «Ви-фразу» на Я-повідомлення («Хто скаже інакше?»), потім з'являється зразок.*

| Замість | Варіант (факт → потреба → прохання) |
|---|---|
| «Не кричіть на мене!» | «Я хочу розібратися у вашій ситуації. Коли говорять дуже голосно, мені важко розчути деталі. Говоріть, будь ласка, спокійніше, я слухаю». |
| «Ви мене не чуєте?!» | «Я вже пояснив, що буде далі. Мені важливо, щоб ми зрозуміли одне одного. Скажіть, будь ласка, як ви це зрозуміли?» |
| «Скільки можна повторювати?» | «Я пояснював це вже двічі. Мені важливо, щоб ви мене зрозуміли. Давайте я скажу ще раз коротко, а ви перепитайте, що незрозуміло». |
| «Ви заважаєте мені працювати» | «Я зараз опитую свідка. Мені потрібні кілька хвилин, щоб нічого не пропустити. Зачекайте, будь ласка, тут, я підійду до вас наступним». |
| «Ви поводитеся як дитина» | «Я бачу, що ситуація вас дуже зачепила. Мені важливо вирішити її спокійно. Тому пропоную сісти й розповісти все по порядку». |
| «Відійдіть від машини!» | «Зараз ми оформлюємо ДТП. Мені потрібно, щоб тут було безпечно для всіх. Тому прошу вас відійти на тротуар». |
