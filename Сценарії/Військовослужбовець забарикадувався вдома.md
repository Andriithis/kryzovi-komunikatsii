# Військовослужбовець забарикадувався вдома

*Військовослужбовець забарикадувався й погрожує «все підірвати». Тільки обговорення, без розігрування.*

**Редагування:** з оригіналу прибрали завершення, де один поліцейський заходить сам, бо це небезпечно.

**Запитання для групи:** завдання комунікації / завдання тактичних дій / момент переходу.
