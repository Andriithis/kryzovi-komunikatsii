# «Чому ви не на фронті?»

*Типова провокація від ветерана чи громадянина. Відповідь має бути нейтральною, без захисту й без нападу.*

Варіант відповіді: «Ми несемо службу тут, щоб підтримувати порядок, зокрема й для вашої безпеки».

Фраза також є у вправі [[Пінг-понг — відповідь за 5 секунд]].
