# Ветеран, роздратований затримками ВЛК

*Розгніваний, але неозброєний ветеран через затримки військово-лікарської комісії. Картка для короткої практики в модулі 3.*

**Що відпрацьовують:** 60–90 секунд: слухати → назвати емоцію → поставити межу → дати варіант дії.

Ключ: за гнівом часто стоїть відчуття несправедливості, «за яку проливали кров». Байдужість поліцейського може посилити спалах.
